# Dimensionality-Reduction
In this repository, I explore dimensionality reduction in datasets and learn how to use PCA and LDA in my datasets to best analyze datasets. First, in the folder labeled "Learning PCA", I created a project where I implement PCA and utilize its dimensionality reduction efficiently. Next, in the folder labeled "Learning PCA and LDA", I explore the additional of LDA in datasets and the difference between variance explanation between each dimensionality reduction method. Finally, in the folder labeled "Final-Project", I use PCA and LDA to accurately identify the main factors that lead to breast cancer. Using PCA and LDA, the top factors that contribute to whether cancer is benign or malignant are identified, using data-driven decision making. In conclusion, this repository documents the learning process I took to understand PCA and LDA and how each algorithim worked.
